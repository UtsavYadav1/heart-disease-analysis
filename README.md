# Heart Disease SQL & Tableau Analysis

## Overview
This project presents a comprehensive analysis of heart disease data using **SQL** for data extraction/aggregation and **Tableau** for data visualization. The goal is to uncover patterns and risk factors associated with heart disease based on patient health metrics.

## Tools & Technologies
- **SQL**: Used for querying and analyzing the dataset (e.g., aggregating cholesterol levels, identifying age distributions, counting cases by target status).
- **Tableau**: Used to create an interactive dashboard for visualizing the relationship between various health metrics and heart disease.
- **GitHub**: Version control and project showcasing.

## Repository Contents
- `Heart_new2.csv` - The primary dataset used for this analysis, containing patient health records.
- `queries.sql` - The SQL scripts containing the queries used to aggregate and analyze the heart disease data.
- `Healthcare Analysis on Heart Disease.png` - A screenshot of the final Tableau dashboard visualizing the insights.

## Analysis Steps
1. **Data Gathering:** Obtained and cleansed the health metric dataset (`Heart_new2.csv`).
2. **SQL Analysis:** Executed grouped queries to identify correlations between parameters like age, cholesterol, chest pain type, and the likelihood of heart disease.
3. **Visualization:** Developed a visual summary of the findings, highlighting actionable insights for healthcare analysis.
