# Heart Disease SQL & Machine Learning Analysis

## Overview
This project presents a comprehensive analysis of heart disease data using **SQL** for exploratory data extraction, and **Python (Pandas, Scikit-Learn, Seaborn)** for deeper Exploratory Data Analysis (EDA) and predictive modeling. The goal is to uncover patterns and risk factors associated with heart disease and build a basic machine learning model to predict its occurrence based on patient health metrics.

## Tools & Technologies
- **SQL**: Used for querying and aggregating the dataset (e.g., identifying age distributions, matching health conditions to heart disease cases).
- **Python**: 
  - `pandas` for data manipulation.
  - `matplotlib` & `seaborn` for generating visual insights.
  - `scikit-learn` for training a Random Forest classification model.
- **Tableau**: Used to create an interactive dashboard for visualizing the relationship between various health metrics and heart disease.
- **GitHub**: Version control and project showcasing.

## Repository Contents
- `Heart_new2.csv` - The primary dataset used for this analysis, containing patient health records.
- `queries.sql` - SQL scripts containing the grouping and aggregation queries to analyze the heart disease data based on the features available.
- `analysis.py` - The Python script responsible for cleaning the data, generating EDA plots, encoding categorical variables, and training the predictive Machine Learning model.
- `requirements.txt` - Python package dependencies needed to run the analysis script.
- `heart_disease_distribution.png` & `bmi_vs_heart_disease.png` - Visualizations generated by the Python script.
- `Healthcare Analysis on Heart Disease.png` - A screenshot of the original final Tableau dashboard visualizing the insights.

## Analysis Steps
1. **Data Gathering:** Obtained and evaluated the health metric dataset (`Heart_new2.csv`).
2. **SQL Analysis:** Executed grouped queries (`queries.sql`) to identify correlations between parameters like BMI, Smoking, Age Category, other comorbidities, and the likelihood of heart disease.
3. **Python EDA:** Used `seaborn` to visually explore the distribution of heart disease cases and the relationship between numerical features like BMI and the target variable.
4. **Machine Learning Modeling:** Preprocessed the categorical variables using Label Encoding and trained a `RandomForestClassifier` to predict heart disease presence. Evaluated the model using accuracy and a classification report.
5. **Visualization:** Developed a visual summary of the findings using both generated plots and a Tableau dashboard to highlight actionable insights for healthcare analysis.

## How to Run the Python Script
To run the analysis locally, ensure you have Python installed, then execute:

```bash
pip install -r requirements.txt
python analysis.py
```
